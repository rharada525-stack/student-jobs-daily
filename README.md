# 受講生サポート：毎日更新の案件リンク

ココナラ・クラウドワークスの公開募集ページを毎日7:23（日本時間）に取得します。GitHub側の混雑により遅れる場合があります。ランサーズ・ママワークスは公式検索へのリンクのみです。

公開案件のタイトル・予算・期限・元URLのみを保存します。募集本文は転載しません。学生の名前・プロフィール・作品URLは扱いません。AIや有料APIは使いません。

標準のGitHub-hosted Linuxランナーを公開リポジトリで使用します。Actionsの追加の成果物保存・キャッシュは使いません。日々の更新状態をコミットするため、通常運用ではリポジトリに毎日活動があります。

失敗時は前回の正常データと正常更新日時を維持し、失敗状態を表示します。期限切れは表示側でも除外します。キーワード除外は安全性を保証しません。

手動実行：Actions → Daily public job links → Run workflow。
