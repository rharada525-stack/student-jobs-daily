# 受講生サポート：毎日更新の案件リンク

毎日7:23（日本時間）にGitHub Actionsで公開ページの更新を試行します。標準Linuxランナー・公開リポジトリ・有料AI/APIなし。GitHubの混雑時は遅れる場合があります。

2026-10-14の実地確認：ココナラ・ママワークスはGitHub上で取得成功。ランサーズはHTTP 405、クラウドワークスはHTTP 403が返りました。ローカルでは通常のHTTP取得に成功したため、初回の確認済みデータだけを登録しています。この2サービスの日次取得はまだ成功確認できていません。アクセス制限の回避・プロキシ・Cookie持ち込みはしていません。

ランサーズ・ママワークスの掲載項目はタイトル・報酬・元ページへのリンクのみ（内部IDを含む）。募集本文・画像は転載しません。学生の個人情報は扱いません。

クラウドワークスは募集本文を確認し、指定14語・家族/職業/居住質問・年代や受講経験・高収入誘導・初心者訴求の重複を除外します。公開発注者プロフィールで評価件数と契約件数を確認し、0件/確認不能も掲載しません。募集実績だけでは通しません。本文・発注者情報は判定時のメモリー内だけで使い、公開JSONには保存しません。除外条件の通過は安全性の保証ではありません。

取得失敗時は前回の正常データと日時を維持し、サイトに更新失敗を表示します。クラウドワークスは現行除外条件で確認済みの前回データのみ再利用します。旧条件のスナップショットを表示しません。

手動実行：Actions → Daily public job links → Run workflow。
